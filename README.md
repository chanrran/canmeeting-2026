# 2026 캔미팅 — 우리 팀 사용설명서

워크숍 당일 진행용 웹 앱입니다. 서버 없이 **GitHub Pages(화면)** + **Firebase(데이터 저장)** 로 동작합니다.

## 파일 구성

| 파일 | 역할 | 주소 |
|---|---|---|
| `index.html` | 참가자 화면 (휴대폰) | `https://아이디.github.io/canmeeting-2026/` |
| `screen.html` | 큰 화면 (빔프로젝터·TV) | `…/canmeeting-2026/screen.html` |
| `host/index.html` | 진행자 화면 (노트북) | `…/canmeeting-2026/host/?key=관리자암호` |
| `config.js` | **팀장님이 고치는 유일한 파일** (Firebase 값, 관리자 암호, 처음 명단, 기초 프롬프트). 명단은 진행자 화면에서도 고칠 수 있음 | |
| `app.js`, `style.css`, `qrcode.js` | 공통 코드·디자인·QR 생성기 (고치지 않아도 됨) | |

## 0. 먼저 데모 모드로 체험해 보기 (5분, 설치 없음)

`config.js`의 Firebase 값이 비어 있으면 **데모 모드**로 동작합니다. 이 컴퓨터의 이 브라우저 안에서만 저장되지만, 세 화면이 서로 연결되는 것을 그대로 볼 수 있습니다.

1. 압축을 푼 폴더에서 `host` 폴더 안의 `index.html`을 **Chrome**으로 엽니다.
2. 주소창 맨 끝에 `?key=canmeeting2026` 을 붙이고 Enter → 진행자 화면이 나옵니다.
3. 오른쪽 위 **"큰 화면 열기 ↗"**, **"참가자 화면 열기 ↗"** 를 각각 누릅니다. (탭 3개)
4. 진행자 화면 맨 아래 **"테스트 데이터 생성"** 을 두 번 누르면 14명의 가짜 입력이 채워집니다.
5. 진행자 화면 왼쪽의 단계 버튼을 눌러 가며 큰 화면이 바뀌는 것을 확인합니다.
6. 다 봤으면 **"전체 초기화"** 를 두 번 눌러 지웁니다.

> 파일을 더블클릭해서 열었을 때 화면이 안 바뀌면, Chrome 대신 다른 브라우저를 쓰고 있는지 확인해 주세요.

## 1. Firebase 만들기 (약 15분, 무료)

> 메뉴 이름은 2026년 9월 기준 추정입니다. Firebase 화면이 조금 다를 수 있으니, 비슷한 이름을 찾아 눌러 주세요.

| 단계 | 할 일 | 결과 |
|---|---|---|
| 1 | https://console.firebase.google.com 접속 → Google 계정 로그인 → **"프로젝트 추가"** (또는 "프로젝트 만들기") | 프로젝트 이름 예: `canmeeting-2026`. Google 애널리틱스는 **사용 안 함** |
| 2 | 왼쪽 메뉴에서 **Firestore Database** → **"데이터베이스 만들기"** | 위치: `asia-northeast3 (서울)`. 시작 모드: **"테스트 모드"** |
| 3 | 왼쪽 메뉴에서 **Authentication** → **"시작하기"** → **"로그인 방법"** 탭 → **"익명"** → 사용 설정 → 저장 | |
| 4 | 같은 Authentication → **"설정"** 탭 → **"승인된 도메인"** → **"도메인 추가"** → `아이디.github.io` 입력 | GitHub 주소에서 로그인이 막히지 않게 합니다 |
| 5 | 왼쪽 위 **톱니바퀴 → "프로젝트 설정"** → 아래 **"내 앱"** → 웹 아이콘 **`</>`** → 앱 닉네임 입력 → **"앱 등록"** | `firebaseConfig = { apiKey: "...", ... }` 형태의 값이 나옵니다 |
| 6 | 그 값 6개(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)를 `config.js`의 같은 이름 줄 따옴표 안에 하나씩 붙여넣기 | 이 값은 공개되어도 되는 값입니다(비밀번호 아님) |
| 7 | Firestore Database → **"규칙"** 탭 → 내용을 모두 지우고 아래를 붙여넣기 → **"게시"** | 익명 로그인한 사용자만 읽고 쓸 수 있습니다 |

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

## 2. GitHub Pages에 올리기 (약 10분, 무료)

| 단계 | 할 일 | 결과 |
|---|---|---|
| 1 | https://github.com 로그인 → 오른쪽 위 **"+"** → **"New repository"** | 이름: `canmeeting-2026`, **Public**, "Add a README file" 체크 → **"Create repository"** |
| 2 | 저장소 화면에서 **"Add file" → "Upload files"** | |
| 3 | 압축을 푼 폴더 안의 **파일 전부와 `host` 폴더**를 한꺼번에 끌어다 놓기 → **"Commit changes"** | `host` 폴더째 올라갑니다 (Chrome 기준) |
| 4 | **"Settings"** → 왼쪽 **"Pages"** → Source: **"Deploy from a branch"** → Branch: **`main`** / **`/(root)`** → **Save** | 1-3분 뒤 위쪽에 주소가 나옵니다: `https://아이디.github.io/canmeeting-2026/` |
| 5 | 그 주소를 `config.js`의 `PARTICIPANT_URL` 따옴표 안에 넣고, `config.js`만 다시 올리기 (Add file → Upload files) | 큰 화면 QR이 이 주소를 가리킵니다 |

> `host` 폴더가 안 올라갔다면: **"Add file" → "Create new file"** → 파일 이름 칸에 `host/index.html` 입력 → 내용 칸에 `host/index.html` 파일 내용을 전부 붙여넣기 → Commit.

**수정할 때**: 고친 파일을 같은 방법으로 다시 올리면 덮어써집니다. 반영까지 1-3분.

## 5. 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 화면 위에 빨간 띠로 오류가 나옴 | 띠에 적힌 안내를 먼저 따라 주세요 |
| 화면이 하얗고 아무것도 안 나옴 | `config.js`에 붙여넣은 값의 따옴표·쉼표가 지워지지 않았는지 |
| "권한이 없습니다" | Firestore 규칙을 **게시**했는지, Authentication에서 **익명**을 사용 설정했는지 |
| 입력했는데 큰 화면에 안 나옴 | 큰 화면 새로고침(F5). 그래도 안 되면 인터넷 연결 |
| 테스트 모드 30일이 지나 저장이 안 됨 | 위 1장 7단계 규칙을 게시했다면 해당 없음 |
| 팀 사용설명서 슬라이드가 한 장뿐 | 붙여넣은 결과에 `## `로 시작하는 제목 줄이 있는지 |
| 참가자가 이름을 잘못 눌렀음 | 휴대폰 화면 맨 아래 "다른 이름으로 로그인" |

## 6. 알아 두실 점

- **칭찬 익명성**: 칭찬에는 보낸 사람이 저장되지 않고, 배정표는 진행자 화면에도 나오지 않습니다. 다만 배정표 자체는 데이터베이스에 있으므로, 개발자 도구를 열어 들여다보면 누가 누구에게 쓰는지는 알 수 있습니다(내부 워크숍 수준의 익명성).
- **칭찬 배정**: "사용설명서 + 칭찬 입력" 단계에 들어갈 때 자동으로 각자 두 명이 배정됩니다. 본인은 배정되지 않고, 전원이 정확히 두 건씩 받으며, 서로 맞칭찬하는 짝은 생기지 않습니다.
- **AI**: 앱은 AI를 직접 부르지 않습니다. 진행자 화면이 프롬프트를 만들어 주면 Claude·GPT 채팅에 붙여넣어 쓰는 방식입니다.
- **명단 변경**: 진행자 화면의 "참가자 명단"에서 추가·수정·삭제 후 "저장"하면 모든 화면에 바로 반영됩니다.
- **문구 변경**: `config.js`의 `BASE_PROMPT`(기초 프롬프트), `EVENT_DATE`(행사일), `TEAM_NAME`(팀 이름), `EMOTION_MONTHS`(감정 곡선 입력 달 수)를 고치면 됩니다.
